# Lamak Bana — UTS Front-End Programming

Lamak Bana adalah website restoran khas Minang yang dikembangkan untuk memenuhi proyek Ujian Tengah Semester mata kuliah Front-End Programming.

Project terdiri dari dua bagian utama:

- **Landing Page** untuk pelanggan
- **Admin Dashboard** untuk pengelolaan operasional restoran

Website dikembangkan secara kolaboratif menggunakan Git dan GitHub.

## Fitur Utama

### Landing Page

- Hero Section interaktif
- Navigasi antar-section
- Daftar Menu Makanan
- Menu dinamis dari data Admin
- Pemesanan Menu
- Promo
- Katering
- Reservasi
- Tentang Kami
- Kenapa Kami
- Status buka/tutup restoran
- Footer dan Social Media
- Responsive Design
- Animasi dan Hover Interaction
- Back to Top
- Skip to Content

### Admin Dashboard

- Security Check / Login Admin
- Dashboard operasional
- CRUD Menu Makanan
- Manajemen Pesanan
- Manajemen Reservasi
- Manajemen Katering
- Manajemen Promo
- Laporan penjualan
- Filter dan pencarian data
- Sinkronisasi data dengan Landing Page menggunakan localStorage
